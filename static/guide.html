🔧 서버가 다운됐을 때 복구 (Termius 사용)

🚨 163.192.35.70:5000 접속이 안 될 때만 사용. 평소에는 자동 배포로 충분합니다.

상황 1: 서버가 잠깐 죽은 경우 (run.sh가 돌고 있었음)

run.sh 루프가 3초마다 자동 재시작하므로 그냥 기다립니다. 그래도 안 되면:

cd /home/ubuntu/chart && pkill -f server.py; sleep 1; nohup bash run.sh >> server.log 2>&1 &

상황 2: 서버가 완전히 꺼진 경우 (재부팅 등)

# 1. 접속 후 실행
cd /home/ubuntu/chart
git pull origin main
pkill -f server.py 2>/dev/null
nohup bash run.sh >> server.log 2>&1 &
sleep 3
curl -s localhost:5000/api/status

마지막 줄에 {"status":"running"...} 나오면 성공.

상황 3: 코드가 없는 경우 (서버 새로 셋업)

# 패키지 설치
pip3 install flask flask-cors yfinance pandas numpy

# 코드 클론
cd /home/ubuntu
git clone https://github.com/bsu3011-ux/chart.git chart
cd chart

# 서버 시작
nohup bash run.sh >> server.log 2>&1 &

상황 4: 자동 재시작 크론잡 설정 (한 번만)

서버 재부팅 후에도 자동으로 뜨게 하려면:

(crontab -l 2>/dev/null; echo "@reboot cd /home/ubuntu/chart && nohup bash run.sh >> server.log 2>&1 &") | crontab -

🐛 자주 발생하는 문제

증상원인해결법
화면이 완전히 안 켜짐 (흰 화면) JSX 문법 오류 → Babel 파싱 실패 브라우저 콘솔(F12) 확인. Claude에게 에러 메시지 전달
변경사항이 반영 안 됨 브라우저 캐시 Ctrl+Shift+R 또는 시크릿 창
● 데모 표시 (서버 연결 안 됨) API fetch 실패 163.192.35.70:5000/api/status 직접 확인
종목 검색 후 "분석 실패" yfinance Yahoo Finance 연결 오류 서버 서버로그 확인: tail -50 /home/ubuntu/chart/server.log
지도가 안 나옴 D3/TopoJSON CDN 로드 실패 잠시 후 자동 재시도 (200ms 루프 내장). 안 되면 새로고침
배포했는데 반영 안 됨 run.sh가 안 돌고 있음 (pkill 후 재시작 불가) Termius에서: cd /home/ubuntu/chart && nohup bash run.sh >> server.log 2>&1 &
git push 실패 네트워크 불안정 Claude가 자동 재시도 (최대 4회: 2s→4s→8s→16s)
Unexpected token 'N' (NaN JSON) Python NaN이 JSON으로 직렬화됨 server.py의 _clean() 함수가 처리 (이미 수정됨)

GitHub webhook 수동 테스트

python3 -c "
import hmac, hashlib, urllib.request, json
body = b'{\"ref\":\"refs/heads/main\"}'
sig = 'sha256=' + hmac.new(b'stockbot-deploy-2024', body, hashlib.sha256).hexdigest()
req = urllib.request.Request('http://localhost:5000/deploy', data=body,
      headers={'X-Hub-Signature-256': sig, 'Content-Type': 'application/json'})
print(urllib.request.urlopen(req).read().decode())
"

⚙️ GitHub Webhook 설정 확인

자동 배포가 안 된다면 GitHub webhook이 설정됐는지 확인:

  1. GitHub → bsu3011-ux/chart → Settings → Webhooks
  2. Payload URL: http://163.192.35.70:5000/deploy
  3. Content type: application/json
  4. Secret: stockbot-deploy-2024
  5. Events: Just the push event
